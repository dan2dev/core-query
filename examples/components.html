Components

Small interactive examples of state, conditions, lists and native components. Change the controls and watch what happens: the data-* attributes connect the HTML to the state, with no element to select by hand.

1. Tabs: the state picks the content

Click a tab. data-click updates tab; data-if and data-else-if pick which panel to render. Edit the name or change the notifications option to see fields bound to the state.

Hello, ! Edit your name:

You will get notifications.

The content of a closed tab is unmounted; its state stays in the tree.

2. Conditions: remove or just hide

Check and uncheck the box. data-if mounts or unmounts the paragraph; data-show keeps the element in the DOM and toggles its hidden attribute. Use data-if for conditional content and data-show when you only want to control visibility.

This text is in the DOM only while the box is checked.

This text stays in the DOM, but is hidden when the box is unchecked.

3. List: add, count and remove items

Submit the form to add an item. data-for repeats an element for each item, data-text shows its text, and item.delete() removes the row clicked. The count follows the list.

The list is empty. Add your first item above.

4. Modal, notifications and a native popover

The modal state opens or closes the <dialog>; the notifications leave after three seconds or on a click on ×, animated by data-transition. The popover uses the browser's API and needs no JavaScript.

A popover without a line of JS: a click outside or Esc closes it.

Delete the project?

Esc, "Cancel" or a click outside close it.

5. Accordion: native HTML

Open a question to read its answer. <details name="faq"> keeps a single answer open at a time, with no interaction code.

6. Range and progress: one value, three views

Drag the control. data-value writes the value, data-attr-value updates the progress bar and data-text shows the number.
